**Proceso BPMN – Gestión de pedidos**

**Descripción del proceso**
El proceso representa la gestión de pedidos de Moda Urbana, desde que el cliente realiza una compra hasta que el pedido queda preparado para su envío.

**Participantes**
- **Cliente:** realiza el pedido a través de la tienda online.
- **Sistema Web:** registra el pedido, verifica la disponibilidad de stock, calcula el total y confirma la compra.
- **Depósito y Logística:** prepara el pedido para su envío.

**Secuencia de actividades**
1. El cliente realiza un pedido.
2. El sistema registra los datos del pedido.
3. El sistema verifica la disponibilidad de stock.
4. Se evalúa si hay stock suficiente:
   - **Sí:** el sistema calcula el total y confirma el pedido. Luego, Depósito y Logística prepara el pedido para su envío.
   - **No:** el sistema informa la falta de stock y finaliza el proceso sin confirmar el pedido.
